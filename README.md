# FreshBite - Online Food Ordering

Task ID: WD-EC-001  
Student Code: DAS-EC-001  
Industry: Food & Restaurant  
Company: Data Alcott Systems

## Objective
FreshBite is a responsive frontend-only online food ordering website.

## Technologies
- HTML5
- CSS3
- JavaScript
- LocalStorage for cart persistence

## Features
- Home page and hero section
- Restaurant listing
- Food categories and dietary filters
- Food menu
- Add to cart
- Quantity adjustment
- Price and delivery calculation
- Checkout form
- Simulated login/register
- About Us
- Contact Us
- Responsive mobile navigation
- Simulated order placement

## Run
Open `index.html` in a modern web browser.
